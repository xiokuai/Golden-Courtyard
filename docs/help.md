# 使用帮助

## 快速上手

1. 打开应用，注册一个账号并登录
2. 点击左侧 `+` 按钮创建服务器，或通过邀请码加入已有服务器
3. 在频道列表中选择频道，开始聊天

---

## 服务器管理

**创建服务器**
- 点击左侧服务器栏底部的 `+` 按钮
- 输入服务器名称即可创建，系统自动生成邀请码

**加入服务器**
- 点击 `+` 按钮，切换到"加入服务器"选项卡
- 输入邀请码即可加入

**邀请码**
- 右键点击服务器图标，选择"邀请码"查看
- 将邀请码分享给其他用户

**服务器图标**
- 服务器所有者可右键点击服务器图标，选择"更换图标"上传自定义图标
- 支持常见图片格式，限制 2MB

**退出/删除服务器**
- 右键点击服务器图标，选择"退出服务器"或"删除服务器"（仅所有者）

---

## 频道

**创建频道**
- 点击频道列表顶部的 `+` 按钮，输入频道名称

**删除频道**
- 仅所有者和管理员可以删除频道

**未读消息**
- 有未读消息的频道会显示角标数字
- 进入频道后自动标记为已读

---

## 消息功能

**发送消息**
- 在底部输入框输入内容，按 Enter 发送

**回复消息**
- 将鼠标悬停在消息上，点击回复按钮
- 回复栏会显示在输入框上方，点击 × 可取消

**编辑消息**
- 将鼠标悬停在自己的消息上，点击编辑按钮
- 修改后按 Enter 保存，按 Esc 取消

**删除消息**
- 将鼠标悬停在自己的消息上，点击删除按钮

**Markdown 格式**
- `**粗体**` → **粗体**
- `*斜体*` → *斜体*
- `` `代码` `` → `代码`
- ` ```代码块``` ` → 代码块
- `~~删除线~~` → ~~删除线~~
- `[链接](url)` → 可点击链接
- 直接粘贴 URL 会自动变为链接

**加载历史**
- 滚动到顶部自动加载更早的消息

---

## 私信

**发起私信**
- 点击左侧服务器栏顶部的私信按钮（聊天气泡图标）
- 在搜索框中搜索用户名，点击用户发起对话
- 也可以在成员列表中右键点击成员，选择"发送私信"

**未读私信**
- 私信列表中会显示未读消息数
- 打开对话后自动标记为已读

---

## 成员管理

**查看成员**
- 右侧面板显示当前服务器的成员列表
- 在线成员和离线成员分组显示

**用户资料卡片**
- 点击任意成员可查看资料卡片
- 显示头像、用户名、状态消息、角色和在线状态

**角色管理**（仅所有者）
- 右键点击成员，可设置为管理员或普通成员

**踢出成员**（所有者和管理员）
- 右键点击成员，选择"踢出"
- 管理员不能踢出其他管理员

---

## 个性化

**头像**
- 点击左下角用户栏的头像即可上传新头像
- 支持常见图片格式，限制 2MB

**状态消息**
- 点击用户栏中用户名下方的状态文字
- 输入自定义状态（最多 100 字），留空可清除

**主题设置**
- 点击用户栏中的 ⚙ 按钮打开主题面板
- 可切换深色/浅色模式
- 可选择 6 种主题色（紫、蓝、青、绿、橙、粉）
- 设置自动保存到浏览器，下次打开自动恢复

---

## 移动端

- 屏幕宽度 ≤ 768px 时自动切换为移动布局
- 点击左上角汉堡菜单按钮展开侧栏
- 选择频道后侧栏自动收起

---

## 快捷操作

| 操作 | 方式 |
|------|------|
| 发送消息 | Enter |
| 取消编辑 | Esc |
| 取消回复 | 点击回复栏 × |
| 查看邀请码 | 右键服务器图标 |
| 发送私信 | 右键成员 |
| 更换头像 | 点击左下角头像 |
| 设置状态 | 点击状态文字 |
| 主题设置 | 点击 ⚙ 按钮 |
